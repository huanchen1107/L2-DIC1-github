# 👋 Hello — Huan Chen

A sleek, single-page personal greeting card built with pure HTML, CSS, and JavaScript.  
No frameworks. No dependencies. Just clean code and a premium design.

🔗 **Live Demo: [https://huanchen1107.github.io/L2-DIC1-github/](https://huanchen1107.github.io/L2-DIC1-github/)**

---

## ✨ Features

- **Live Clock** — Displays the current time (hours, minutes, seconds) updated every second
- **Live Calendar** — Shows today's full date (weekday, month, day, year)
- **Dark Mode UI** — Deep dark background with glassmorphism card design
- **Animated Glows** — Subtle ambient background light animations
- **Hover Effects** — Smooth card lift and shimmer on hover
- **Responsive** — Works on any screen size

---

## 🚀 Getting Started

No build tools or installation required. Just open the file in your browser:

```bash
# Clone the repository
git clone https://github.com/huanchen1107/L2-DIC1-github.git

# Open the page
cd L2-DIC1-github
start index.html     # Windows
open index.html      # macOS
```
